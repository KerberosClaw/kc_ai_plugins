# 對帳：把好幾份結果併成一份

會用到這份的時候：

- 同一套系統修完一批、又跑了一輪，要知道「到底好了幾條、又壞了幾條」
- 一個人做 QA，讓 AI 換幾個視角各挖一遍（最後一節），要收成一份清單

兩種情況做的是同一件事：**對帳**。把每一份結果當成一本帳，逐條比，每一條都要有個去處。

## 第一步：排成一張對帳表

以發現編號與案例編號為列，每一份結果（`R1`、`R2`⋯，或 `產品`、`品質`⋯）各佔一欄：

```
                 R1                  R2                  結果
TC-03 上傳單張   FAIL P1  img/r1/…   PASS     img/r2/…   已修好
TC-07 批次匯入   UNCLEAR P2          UNCLEAR P1          延續，嚴重度不同
TC-11 刪除分類   —                   FAIL P0  img/r2/…   本輪新增
UND-02 要管理員  待判定              待判定              延續
```

格子裡照抄那一份原本寫的東西：狀態、嚴重度、證據位置。**不要在排表的時候順手修正或潤飾**，這張表的價值就在於它是原樣。

## 第二步：替每一列決定去處

| 對帳結果 | 怎麼認定 | 報告裡怎麼寫 |
|---|---|---|
| 已修好 | 前一輪不是 `PASS`，這一輪 `PASS`，而且**有這一輪自己的證據** | 列進「本輪修正」，附兩輪的圖對照 |
| 延續 | 兩輪都不是 `PASS` | 照常列，標出第一次出現在哪一輪 |
| 本輪新增 | 前一輪沒有這一列，或前一輪 `PASS` 這一輪壞了 | 後者特別標出來：這是退步 |
| 補跑 | 前一輪 `NOT RUN`，這一輪跑了 | 照這一輪的結果列，註明是補跑 |
| 說法衝突 | 狀態或嚴重度兩邊不一樣，而且不是上面任何一種 | 進報告「分歧」一節，兩邊原樣並排 |
| 看不出是不是同一列 | 兩份的描述像是同一件事，但不確定 | **分開列**，開一條待答問題問是不是同一件事 |

🔴 **「已修好」只認這一輪的證據。** 開發回報「修好了」、commit 訊息寫了 fix，都只能讓這一列排進這一輪要重跑的清單，不能直接改成 `PASS`。

最後一種要特別小心。兩條看起來像的發現，如果其實是兩個問題，併成一列之後其中一個就從報告裡消失了；分開列最多只是多一行。

## 第三步：嚴重度與排序

嚴重度欄**把每一份給的值並排寫出來**，例如 `R1:P1 / R2:P3`，不要濃縮成一個數字。

報告需要排序時，按每一列出現過的**最高**等級排。這樣只要有任何一份認為它是 P0，它就一定排在最前面，不會因為其他幾份給得比較低就沉下去。排序用的等級旁邊保留並排的原值，讀的人一眼看得出這一列有爭議。

## 第四步：寫進報告之前

對帳表本身附在報告最後。正文只寫第二步的結論，而且每一句都要能回指到對帳表的某一列。對帳過程中冒出來的猜測（「應該是同一個根因」「大概是快取」）不進正文，要寫就寫成待答問題並註明是猜的。

### 上線壓力怎麼記

對帳時常會遇到「這條已經決定先上線」這種訊息。它不影響那一列的狀態，`FAIL` 還是 `FAIL`。在那一列旁邊加註「風險接受：誰、何時、理由」，讀報告的人就知道這是有人拍板的，不是漏看的。

## 多視角挖掘

一個人做 QA 時，可以讓 AI 換幾個角度各挖一遍，再用上面的對帳表收成一份。四個角度各問不同的事：

| 視角 | 問什麼 |
|---|---|
| 產品 | 這條路徑符合當初想達成的目的嗎？誰被擋在外面了？ |
| 品質 | 什麼情況會壞？壞了看得出來嗎？怎麼驗證？ |
| 技術 | 契約、狀態、錯誤處理、邊界在程式碼裡實際長什麼樣？ |
| 使用體驗 | 走到這一步的人知道發生什麼事嗎？下一步該做什麼？ |

四個視角就是對帳表的四欄。收完是**一份**清單，每一列看得出哪幾個視角提過，不要按視角拆成四個章節讓讀者自己比對。

### 🔴 每個視角先問自己用不用得上

開挖之前，每個視角先看手上的材料跟自己有沒有關係。沒關係就回「不適用」加一句理由，然後停手，那一欄在對帳表裡整欄標「不適用」。

例如這一輪只有後端，沒有畫面可看，使用體驗視角就該直接退出，不要對著 API 規格想像畫面長什麼樣。

**這是多視角最容易壞掉的地方。** 少了這道檢查，四個視角都會硬交出東西，併起來看起來很豐富，其實有一半是編的。

## 對帳做完的檢查

- 前一輪的每一列，在這一輪都找得到去處嗎？（沒有去處的，就是被漏掉的）
- 每一條「已修好」都附了這一輪的證據嗎？
- 有沒有哪一列的嚴重度只剩一個值，看不出原本各份給了什麼？
